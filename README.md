# Analista-IA---Ventas

## Requisitos

- Google Colab
- Archivo `ventas_marzo_2026.csv`
- Cuenta de Groq
- API Key de Groq guardada en Colab Secrets como `GROQ_API_KEY`

## Ejecución

1. Abrir el notebook en Google Colab.
2. Crear una API Key en Groq.
3. Guardarla en Colab Secrets con el nombre `GROQ_API_KEY`.
4. Ejecutar las celdas en orden.
5. Subir `ventas_marzo_2026.csv` cuando el notebook lo solicite.
6. Abrir la interfaz Gradio al final.
